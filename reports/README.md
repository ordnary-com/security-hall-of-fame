# Reports

One file per report: `YYYY-MM-DD-short-slug.md`, copied from
[`TEMPLATE.md`](TEMPLATE.md). The file is the record of the report from
first contact to publication.

Keep this repository private while any report in it is unfixed. Before
making it public, check that every report is `Fixed` or `Closed` and that
nothing in it identifies a researcher who did not agree to be named.

## Status

- `Received`: acknowledged, not assessed yet
- `Accepted`: valid and in scope, fix in progress
- `Fixed`: fix is live
- `Closed`: out of scope, duplicate, or not a vulnerability
